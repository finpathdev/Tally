Tally didn’t start

If this is your site, GitHub Pages is publishing the project’s source files instead of the built app. To fix it:

  1. Make sure package.json, index.html and the .github folder are at the top level of the repository, not inside a subfolder.
  2. Open the repository’s Settings → Pages, and under Build and deployment set Source to GitHub Actions.
  3. Open the Actions tab, choose Deploy app to GitHub Pages, and click Run workflow. The site updates in about a minute.

Visitors: try again in a few minutes, or use a current version of Chrome, Edge, Safari or Firefox.
